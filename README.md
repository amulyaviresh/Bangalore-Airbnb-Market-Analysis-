# Bangalore Airbnb Market Analysis

## Project Overview

This project analyzes the Airbnb rental market in **Bangalore** using **Power BI**.

The dataset contains approximately **6,000 records** covering Airbnb listings across different neighbourhoods, room types, property types, pricing levels, occupancy rates, bookings, reviews, and estimated revenue.

The objective of the project is to understand the factors that influence **pricing, occupancy, bookings, and revenue** in the Bangalore Airbnb market.

## Objectives

* Analyze Airbnb listings across Bangalore.
* Compare prices across different neighbourhoods and property types.
* Analyze occupancy and booking patterns.
* Identify high-revenue neighbourhoods and property types.
* Study the relationship between price, occupancy, ratings, and revenue.
* Analyze seasonal and monthly trends.
* Understand guest origin patterns.
* Build an interactive Power BI dashboard for market analysis.
